# Taller de gráficos en Flutter

Taller que compara cuatro librerías de gráficos de Flutter (syncfusion_flutter_charts,
fl_chart, graphic y flutter_echarts). Cada una muestra 63 gráficas con datos reales
de la API de Rick and Morty.

El proyecto Flutter está en la carpeta [`taller_graficos_unificado/`](taller_graficos_unificado/).
Para abrirlo, se abre esa carpeta (no la raíz del repositorio) en VS Code o Android Studio,
y se corre:

```bash
cd taller_graficos_unificado
flutter pub get
flutter run
```

La descripción completa, la estructura y las pruebas están en
[taller_graficos_unificado/README.md](taller_graficos_unificado/README.md).
